# AATOS Onboarding Journeys

## Supplier Onboarding Journey (Kenya)

### Step 1: Account Creation
- User enters email, password, first name, last name
- Email verification via OTP
- Phone verification via SMS (optional but recommended)
- **Time**: < 2 minutes

### Step 2: Organization Profile
- Select organization type: Farmer / Cooperative / Processor / Exporter
- Enter organization name, country (Kenya), region, city
- Enter business registration number
- Upload business registration certificate
- **Time**: 5-10 minutes

### Step 3: Verification
- System automatically verifies email and phone
- Business registration verified against Kenya BRS (1 business day)
- Tax compliance checked via KRA API (1 business day)
- Physical site verification scheduled (5 business days)
- Bank account verified via micro-deposit (3 business days)
- **Time**: 3-7 business days total

### Step 4: Product Listing
- Select product category (Green Coffee)
- Enter product specifications:
  - Variety (Arabica/Robusta)
  - Grade (AA, AB, PB, etc.)
  - Altitude
  - Processing method
  - Screen size
  - Moisture content
  - Cupping score
- Upload quality certificate / lab report
- Set pricing (FOB Mombasa)
- Set available quantity and MOQ
- **Time**: 10-15 minutes

### Step 5: Compliance Setup
- System auto-generates compliance checklist for target markets
- Upload required documents:
  - Phytosanitary certificate template
  - Certificate of origin template
  - Export license
- Review and accept platform terms
- **Time**: 10-20 minutes

### Step 6: Go Live
- Profile completeness check (target: 80%+)
- Trust score calculated
- Profile published to marketplace
- Receive first RFQ notification
- **Time**: Immediate

## Buyer Onboarding Journey (United States)

### Step 1: Account Creation
- User enters email, password, first name, last name
- Email verification via OTP
- Phone verification via SMS
- **Time**: < 2 minutes

### Step 2: Organization Profile
- Select organization type: Importer / Distributor / Roaster / Retailer
- Enter organization name, country (United States), state, city
- Enter EIN / business registration number
- Upload business registration certificate
- **Time**: 5-10 minutes

### Step 3: Verification
- System automatically verifies email and phone
- EIN verified via IRS lookup (1 business day)
- CBP importer number verified (1 business day)
- Physical site verification (3 business days)
- Bank account verified via Plaid (instant)
- Trade reference checks (5 business days)
- **Time**: 3-7 business days total

### Step 4: Preferences Setup
- Select preferred product categories
- Set preferred origins (Kenya, Ethiopia, Colombia, etc.)
- Set volume requirements
- Set quality grade preferences
- Set price range
- Set preferred incoterms
- **Time**: 5-10 minutes

### Step 5: First RFQ
- Create first Request for Quotation
- Specify product requirements
- Set delivery timeline
- Set response deadline
- System matches with verified suppliers
- **Time**: 10-15 minutes

### Step 6: Deal Initiation
- Review supplier quotations
- Negotiate terms via messaging
- Accept quotation
- Contract generated automatically
- Milestone payment schedule set
- **Time**: 1-5 business days
