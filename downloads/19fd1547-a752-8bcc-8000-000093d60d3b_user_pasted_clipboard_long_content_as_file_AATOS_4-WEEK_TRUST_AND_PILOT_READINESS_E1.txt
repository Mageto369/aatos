Version: 1.0

Execution Window: Four weeks
Primary Objective: Convert AATOS from a competent software foundation into a verified, legally bounded, operationally usable pilot platform

Pilot Participants: Five verified Kenyan suppliers, five verified U.S. buyers, maximum twenty organizations
Final Decision: Pilot approved, Pilot conditionally approved, or Pilot blocked

1. EXECUTIVE MANDATE

Stop all new feature expansion.

Do not add broad enterprise features, additional corridors, additional commodities, native mobile expansion, AI matching, trade finance, insurance marketplaces, government integrations, white-label capabilities, or advanced analytics during this sprint unless required to support the pilot transaction.

The next four weeks focus only on five areas:

Trust infrastructure

Production engineering

Legal foundation

Pilot operations

Evidence

The purpose of this sprint is not to produce more files.

The purpose is to prove that a real buyer and a real supplier can complete a controlled Kenya-to-United States green specialty coffee transaction through AATOS without direct database manipulation, false claims, unsupported compliance assumptions, insecure payment handling, or undocumented liability.

AATOS must become truthful before it becomes larger.

3. EVIDENCE MODEL

Every requirement must use one of four evidence levels.

L0: No evidence

No reliable decision, implementation, test, runtime proof, or production evidence exists.

L1: Decision documented

The company has made and recorded a decision, but implementation or verification is incomplete.

L2: Implemented in code

Working code exists, but verification is incomplete or limited.

L3: Verified

The feature has passed applicable tests and runtime verification in a clean environment or staging workflow.

Do not upgrade an item to L3 based on code inspection.

Do not upgrade an item to L2 based on documentation alone.

Do not accept screenshots without supporting runtime or database evidence.

Do not accept completion percentages without a supporting evidence table.
